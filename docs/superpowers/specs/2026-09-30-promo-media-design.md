# Промо-слайды и видео на главной и в баннере — 30.09.2026

Просьба владельца: админ загружает на главную (верхний слайдер) не только изображения, но и видео-проморолики; во
всплывающем баннере — выбор «фото или видео». Только владелец/админ (филиалы не видят).

Решения владельца: сначала промо-слайды, потом новинки (в одном слайдере); действие слайда выбирается при настройке —
«Купить товар» (в корзину) или «Перейти в акции»; видео само без звука + кнопка звука; видео до 30 МБ.

## Админка
- «Реклама и акции» → новая вкладка **«Слайдер»** (`?tab=slides`), `HomeSlideManager`.
- Слайд: **Фото / Видео** (переключатель) + загрузка; заголовок и подпись (необязательно); **Действие**:
  «Купить товар» (обязателен товар — ProductPicker) или «Перейти в акции»; показывать/скрыть; порядок ↑↓; изменить; удалить.
- Фото: как у баннера — обрезка до 16:11 JPEG 960×660 в браузере.
- Видео: mp4 / webm / mov, до 30 МБ (иначе ошибка «Видео больше 30 МБ»). В браузере берётся первый кадр → JPEG-обложка
  (poster). Если браузер не смог открыть видео (например, HEVC с iPhone на Android/Chrome) — ошибка «Это видео не
  открывается, сохраните его как MP4». Подсказка под кнопкой: «Лучше MP4 до 30 МБ».
- Баннер (`BannerManager`): переключатель **Фото / Видео**; для видео — та же загрузка + обложка; предпросмотр играет видео.

## Главная
- `HeroSlider` получает список слайдов: сначала активные промо-слайды (по порядку), затем новинки/витрина, как сейчас.
- Промо-слайд с фото: картинка + градиент + заголовок/подпись; «Купить товар» — кнопка «В корзину · цена» (addItem,
  цена с учётом акции), клик по слайду открывает товар; «Перейти в акции» — весь слайд ссылка на `/catalog?promo=1`.
- Видео: `muted playsInline`, `poster`, `preload="metadata"` (без атрибута `loop` — иначе нет события `ended`); играет
  только видимый слайд (остальные на паузе, с начала); кнопка 🔇/🔊 в углу. Пока текущий слайд — видео, таймер
  автолистания стоит; по `ended` — следующий слайд, а если слайд один — ролик начинается заново.
- Нет товара в наличии (для «Купить товар») — слайд не показывается.

## База (`supabase/promo_media.sql`)
- Хранилище `banners`: лимит 30 МБ, типы + `video/mp4`, `video/webm`, `video/quicktime` (политики уже: писать — только
  owner/admin своего магазина в папку `{store_id}/`).
- `banners.video_url text` (обложка — `image_url`).
- `home_slides`: id, store_id, media_type (image|video), image_url (фото или обложка), video_url, title, subtitle,
  action (cart|promo), product_id (on delete set null), priority, active, created_at, updated_at. RLS: читают вошедшие
  в магазин; пишут owner/admin своего магазина (как `new_arrivals`).

## API
- `GET /api/home-slides` — активные слайды магазина по priority, с полным товаром (mapProduct + цена акции); слайды
  «cart» без товара в наличии отбрасываются.
- `GET/POST /api/admin/home-slides`, `PUT/DELETE /api/admin/home-slides/[id]` — только `isStoreManager`.
- Баннеры: `videoUrl` в POST/PUT и `mapBanner`.

## Логика + тесты (`src/lib/home-slides.ts`)
- `validateSlideInput` (действие cart требует товар; video требует video_url; фото — image_url).
- `visibleSlides` (активные, cart — только с товаром в наличии, сортировка по priority).
- `checkVideoFile` (тип и размер ≤ 30 МБ).
- `moveSlide` (перестановка ↑↓ → новые priority).
