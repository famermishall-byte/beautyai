# Push-уведомления (веб-push) — 29.09.2026

Решения владельца: веб-push сейчас (нативные push для приложения-оболочки Capacitor — при публикации в Google Play / App Store);
события — продавцу «новый заказ», клиенту «статус заказа», клиентам «акции и новинки» (рассылка из админки).

## Где работает
Браузер Chrome/Edge/Firefox на Android и компьютере, iPhone — только если приложение добавлено на экран «Домой» (iOS 16.4+).
В Capacitor-оболочке (Android WebView) веб-push нет — переключатель показывает подсказку «откройте в Chrome».

## Кому и что
| Событие | Кому | Текст | Нажатие |
|---|---|---|---|
| Новый заказ (insert в `orders`) | управляющий филиала заказа; владелец и админы магазина | «Новый заказ №48 · 2 010 сом · доставка» | `/ru/admin/orders` |
| Статус заказа (update `status`: paid, shipped, completed, cancelled) или продавец изменил состав (`edited_at`) | клиент заказа | «Заказ №48 оплачен» / «в пути» / «доставлен» / «выдан» / «отменён» / «изменён продавцом» | `/ru/orders` |
| Рассылка (insert в `push_broadcasts`) | все клиенты магазина (role = user) с подпиской | заголовок + текст владельца | ссылка из рассылки или главная |

## Устройство
- **Подписка:** `public/sw.js` (service worker: `push` → `showNotification`, `notificationclick` → открыть/сфокусировать ссылку).
  Клиент (`lib/push.ts`) при включении уведомлений регистрирует SW, подписывается VAPID-ключом и сохраняет подписку в
  `push_subscriptions` (RLS: только свои строки). Выключение — отписка и удаление строки.
- **Отправка — внутри Supabase**, без настроек в Vercel: триггеры на `orders` и `push_broadcasts` через `pg_net` зовут Edge
  Function `send-push` (секрет вебхука в заголовке). Функция service-role ключом (есть в Edge Functions по умолчанию) читает
  получателей и подписки, отправляет через `web-push`, удаляет «мёртвые» подписки (404/410).
- **Секреты** (приватный VAPID-ключ, секрет вебхука) — в Supabase Vault; функция читает их через `push_config()` — SECURITY
  DEFINER, выполнять может только `service_role`. Публичный VAPID-ключ — в коде (он и так публичный).
- **Рассылка:** админка «Реклама и акции» → вкладка «Рассылка»: заголовок, текст, ссылка (необязательно) → insert в
  `push_broadcasts` (RLS: только owner/admin своего магазина). История рассылок с числом отправленных.

## База (`supabase/push.sql`)
`create extension pg_net`; таблицы `push_subscriptions`, `push_broadcasts`; секреты в `vault`; функции `push_config()`,
`notify_push(event, id)`; триггеры `orders_push_insert`, `orders_push_update`, `push_broadcasts_after_insert`.
Ошибка отправки никогда не ломает заказ (pg_net асинхронный).
