# Встроенный баннер на главной — 30.09.2026

Просьба владельца: кроме всплывающих баннеров — второй тип, **встроенный баннер** в прокрутке главной (не popup).
Всплывающие баннеры, акции, каталог, товары, остатки — не меняются.

Решения владельца: одно место — между «Специально для тебя» и «Популярные товары»; на главной всегда **один** баннер
(админ добавляет/удаляет/включает как хочет); нажатие — товар, категория, акции, новинки, каталог; фото или видео,
у видео значок звука вкл/выкл.

## Решение: расширяем `home_slides`, а не второй механизм
`home_slides` (30.09) уже умеет фото/видео, заголовок/подпись, действие, вкл/выкл, порядок, товар. Добавляем:
- `placement` — `hero` (верхний слайдер, как сейчас; значение по умолчанию для всех существующих строк) | `inline`;
- `link_category` — имя группы каталога (`CATEGORY_GROUPS[].name`, ссылка `/catalog?group=<name>`);
- действия: к `cart | promo` добавляются `product | category | new | catalog`.
Разрешённые действия: hero — `cart`, `promo` (как было); inline — `product`, `category`, `promo`, `new`, `catalog`.
Ограничение в базе: не больше одного **активного** inline-баннера на магазин (частичный уникальный индекс).

## Админка
- «Реклама и акции» → новая вкладка **«Баннер на главной»** (`?tab=inline`) — тот же `HomeSlideManager` с `placement="inline"`.
- Форма: MediaPicker (фото/видео), заголовок, текст, «Что открывает нажатие»: Товар (ProductPicker) / Категория
  (выбор группы каталога) / Акции / Новинки / Каталог. Список: миниатюра, заголовок, действие, «Показывается» / «Выключен»;
  кнопки включить/выключить, изменить, удалить. Без стрелок порядка (показывается один).
- Включение одного inline-баннера выключает остальные inline (сервер). Новый баннер создаётся включённым и выключает
  прежний. Подсказка: «На главной показывается один баннер — включённый».
- Вкладка «Слайдер» показывает только `hero` и работает как раньше.

## Главная
- `InlineBanner` сразу после блока «Специально для тебя» (перед «Акции»/«Популярные»). Нет активного — ничего не
  рендерится, главная как сейчас.
- Вид: `aspect-[16/9]`, `rounded-[var(--radius-card)]`, `overflow-hidden`, тень карточки как у блоков главной; если есть
  заголовок/текст — градиент снизу и текст (заголовок `font-display`). Весь баннер — Link по действию.
- Видео: `HeroVideo` (+ `loop`), без звука по умолчанию, значок 🔇/🔊; играет только пока баннер виден
  (IntersectionObserver ≥ 50 %), иначе пауза. Не запустилось — остаётся обложка.
- Товар удалён / нет товара / нет категории — баннер не показывается.

## API
- `GET /api/home-slides?placement=hero|inline` (по умолчанию `hero` — верхний слайдер не получает inline).
- `GET /api/admin/home-slides?placement=…`; POST принимает `placement`, `category`; PUT `{active:true}` для inline
  сначала выключает остальные inline магазина.

## База (`supabase/inline_banner.sql`)
- `alter table home_slides add placement text not null default 'hero' check (placement in ('hero','inline'))`,
  `add link_category text`; заменить check действия на `('cart','promo','product','category','new','catalog')`;
  `create unique index home_slides_one_inline_active on home_slides(store_id) where placement = 'inline' and active`.

## Проверка
Popup-баннер показывается как раньше; слайдер как раньше; встроенный баннер на месте; каждое действие ведёт куда надо;
вкл/выкл из админки; 390 px — аккуратно.
