# Самовывоз / доставка, «Отправлен» и «Доставлен» — 29.09.2026

Просьба владельца: в корзине клиент выбирает самовывоз или доставку (адрес, желательное время, телефон для курьера);
продавец отмечает на листе заказа «Отправлен»; удобно отметить «Доставлен».

Решения владельца: продавец + ссылка курьеру; заказ с доставкой можно отправить до оплаты (оплата курьеру).

## Оформление (корзина)
- «Как получить»: **Самовывоз из филиала** (по умолчанию) / **Доставка**.
- Доставка: адрес (обязательно, ≥ 5 символов, до 300), желательное время (по желанию, до 100, свободный текст),
  телефон для курьера (по желанию; если указан — 9–15 цифр). Подставляются из последнего заказа с доставкой.
- Проверка на сервере (`parseDeliveryInput`, `lib/delivery.ts`); сообщение продавцу в WhatsApp содержит способ
  получения, адрес, время, телефон для курьера (раньше там всегда было «Клиент хочет оформить доставку»).

## Статусы
Старые значения остаются (`sent, confirmed, paid, shipped, completed, cancelled`), меняется смысл и надписи:
- `shipped` — «Отправлен» (продавцу) / «В пути» (клиенту). **Больше не означает оплату**: `paid_at` при нём не ставится.
- `completed` — «Выполнен»; для доставки — «Доставлен», для самовывоза — «Выдан». Всегда ставит `paid_at`, если его не было.
- Продажа = `paid` или `completed`, либо `shipped` с `paid_at` (`isSale`).

Кнопки продавца (`sellerActions`), одинаковые на листе по ссылке и в админке:
| Состояние | Самовывоз | Доставка |
|---|---|---|
| Новый / Подтверждён | Оплата получена · Отменить | Оплата получена · Отправлен · Отменить |
| Оплачен | Выдан клиенту | Отправлен |
| Отправлен | — | Доставлен (если не оплачен — «Оплату получили?») · Переслать курьеру |

## Ссылка курьеру
- У заказа свой `courier_token` (не тот, что у продавца: курьер не может менять состав или отменять).
- `/c/<token>` без входа: номер, адрес + «Открыть на карте», время, клиент + «Позвонить» (основной и курьерский
  телефоны), товары, сумма к оплате (или «Оплачено»), одна кнопка «Доставлен» (если не оплачен — «Доставлен, оплату получил»).
- Продавец после «Отправлен» жмёт «Переслать курьеру в WhatsApp» — открывается WhatsApp с готовым текстом и ссылкой.

## База (`supabase/order_delivery.sql`)
Колонки `orders`: `delivery_method` (pickup|delivery, по умолчанию pickup), `delivery_address`, `delivery_time`,
`courier_phone`, `delivered_at`, `courier_token uuid unique default gen_random_uuid()`.
Функции: обновлённые `set_order_status_by_token` (shipped без оплаты; completed ставит paid_at и delivered_at) и
`get_order_by_token` (+ поля доставки и courierToken); новые `get_order_by_courier_token`, `mark_delivered_by_courier_token`
(только из `shipped`). Всё SECURITY DEFINER с `search_path = public`, как существующие.
