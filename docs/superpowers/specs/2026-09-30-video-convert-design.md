# Конвертация видео в MP4 в админке — 30.09.2026

Просьба владельца: в админке можно выбрать любое обычное видео (MOV и др.); не-MP4 не отклонять, а предлагать
«Видео не в формате MP4. Конвертировать и оптимизировать видео для приложения?» [Отмена] [Да, конвертировать];
после согласия — автоматическая конвертация (FFmpeg, бесплатно), оптимизация для телефонов/веба, звук сохраняется,
затем автоматическая загрузка. Статусы, подтверждение, понятные ошибки + повтор. Один общий компонент. Только админка.

Решения владельца: конвертация в браузере админа (ffmpeg.wasm); исходник до 200 МБ; «особый» MP4 (не открывается
браузером — напр. HEVC — или больше 30 МБ) тоже предлагать конвертировать. Ролики будут короткие.

## Где загружается видео
Только `src/components/admin/MediaPicker.tsx` — используется в «Баннеры» (`BannerManager`), «Слайдер» и
«Баннер на главной» (`HomeSlideManager`). У клиентов загрузки видео нет (аватар — только `image/*`) — не меняется.

## Поведение MediaPicker (режим «Видео»)
- `accept="video/*"` (раньше — только mp4/webm/mov).
- Классификация (`classifyVideo`): > 200 МБ → ошибка «Видео больше 200 МБ — выберите ролик покороче»;
  `video/mp4` ≤ 30 МБ и браузер открыл (обложка снялась) → обычная загрузка, как сейчас;
  иначе → диалог конвертации. Текст: не-MP4 — «Видео не в формате MP4. Конвертировать и оптимизировать видео для
  приложения?»; MP4 > 30 МБ — «Видео больше 30 МБ. Сжать и оптимизировать видео для приложения?»; MP4 не открывается —
  «Это видео может не открыться у части клиентов. Конвертировать и оптимизировать видео для приложения?». Под текстом:
  «На телефоне обработка может занять 1–3 минуты — не закрывайте экран.»
- [Отмена] — закрывает диалог, ничего не загружено. [Да, конвертировать] → статусы: «Подготавливаем видео…»
  (загрузка FFmpeg, чтение файла) → «Конвертируем… N%» → «Оптимизируем…» (проверка размера, обложка) →
  «Загружаем…» → «Видео загружено ✓» (3 с). Во время обработки — кнопка «Отменить» (останавливает FFmpeg).
- Ошибки: FFmpeg не загрузился (нет интернета) / конвертация упала / результат > 30 МБ («Даже после сжатия видео
  больше 30 МБ — выберите ролик покороче») / загрузка упала — текст + «Попробовать снова» (повтор с тем же файлом).

## Конвертация (`src/lib/video-convert.ts`, только браузер)
- `@ffmpeg/ffmpeg` + `@ffmpeg/util`, ядро однопоточное `@ffmpeg/core@0.12.10` (UMD) с cdn.jsdelivr.net через
  `toBlobURL`; импорт динамический — только когда админ нажал «Да» (у клиентов бандл не растёт). Экземпляр
  переиспользуется; «Отменить» → `terminate()` и новый экземпляр при следующем запуске.
- Длительность — из лога FFmpeg (`Duration: HH:MM:SS.xx`) первым проходом `-i in` (или из `<video>` метаданных).
- Параметры (`ffmpegArgs`): `-c:v libx264 -preset veryfast -profile:v high -pix_fmt yuv420p`,
  `-vf scale` — короткая сторона не больше 720 (не увеличивать, чётные размеры), `-b:v`/`-maxrate`/`-bufsize` от
  `targetBitrates(duration)`: общий бюджет 28 МБ, видео ≤ 2500 кбит/с и ≥ 400 кбит/с, звук AAC 128 кбит/с
  (`-c:a aac -b:a 128k`, если звука нет — ffmpeg просто не создаёт дорожку), `-movflags +faststart`.
- Результат `File` `video/mp4`; дальше — тот же путь, что у обычного MP4 (обложка `videoPoster`, `uploadPromoFile`).

## Не меняется
База, хранилище (30 МБ, типы), права, API, показ видео клиентам, каталог, товары, остатки, акции, баннеры.

## Проверка
MP4 грузится как раньше; MOV → диалог → MP4 → загрузка; Отмена/Отменить; ошибка конвертации; > 200 МБ; видео играет
после загрузки; у клиента нигде нет загрузки видео; доступ к админке прежний.
